## 現在のフォーカス

現在は [One Works](https://github.com/oneworks-ai/app) を中心に開発しています。One Works は、coding agents、プラグイン、アダプター、ランタイムデータ、設定体系を、デスクトップ、Web、VS Code、CLI の間で統一するためのオープンソース AI ワークスペースです。

目標はシンプルです。一度設定すれば、どこでも同じワークフローを使えること。One Works は、ツールのインストール、起動、接続、設定、拡張の方法を標準化し、同じプロジェクトをローカルデスクトップ、ブラウザー UI、エディター統合、コマンドライン自動化の間で自然に行き来できるようにします。

## 関心領域

- AI コーディングワークフローのための拡張可能なプラグインアーキテクチャ
- 複数のツールとエントリーポイントを横断する標準化された設定体系
- local-first なデスクトップ体験と Web 体験
- TypeScript、runtime protocol、adapter、開発者ツール
- 毎日使える実用的なオープンソースシステム
